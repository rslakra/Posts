About the Posts IWS

The Posts IWS (Internal Web Service) is the backend of the Posts project. It is a FastAPI application that provides the web pages for accounts, posts, blogs and comments, and a versioned REST API (users, roles, permissions, companies and contacts) that is documented at /docs.
